# Odin Recipes

## Overview
This is a basic recipe site containing a homepage and links to 3 individual recipe pages.
Each recipe page contains an image of the dish, a brief description, ingredients, and the steps to make the dish.

## Demonstrated Skills
This project was developed in pure HTML. While developing these recipe pages, I had hands-on experience 
using HTML elements, tags, and attributes. I learned how to:
* Use anchors to link from one page to another
* Add images and scale them proportionally to the page
* Incorporate headings, ordered lists, and unordered lists to organize and format the contents of the page.
* Use version control for easy tracking and for documenting changes during development.

## Future Improvements and Enhancements
Since these pages were developed in HTML, the styling is very minimal. Once I learn CSS, I would like to return 
to this project and incorporate CSS in order to make the page more unique while also appealing to the user experience.
